## 🌿 Git Workflow

The project follows a feature-branch based Git workflow.

### Main branch

```text
main
```

### Development branch

```text
bytespace-landing-page
```

Development work was completed on the feature branch and prepared for integration through a Pull Request.

### Example workflow

```bash
git checkout -b feature/landing-page

git add .

git commit -m "feat: implement ByteSpace landing page"

git push -u origin feature/landing-page
```

A Pull Request can then be opened from:

```text
feature/landing-page → main
```
